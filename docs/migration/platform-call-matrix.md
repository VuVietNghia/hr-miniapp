## Task 13 composition rule

Task 13 owns the one-time process composition. It creates the SDK Hub client once and injects it;
the gateway and business repositories never instantiate an SDK, OAuth, or Relay client:

```ts
const hubClient = createAgentBotHubClient({ resolveHubOrigin });
const roomPlatform = new AgentBotRoomPlatformGateway(
  hubClient,
  resolveOwnMcpAppId,
);
```

This composition belongs at the application composition root, not inside
`AgentBotRoomPlatformGateway.call()` or a repository method.
