# Job Description: Thực tập sinh / Junior Backend Java Developer

## 1. Thông tin chung
* **Vị trí:** Thực tập sinh / Junior Backend Java Developer
* **Công ty:** Barmy AI
* **Hình thức:** Full-time hoặc Part-time (tối thiểu 4 ngày/tuần)
* **Mức lương:** Thỏa thuận theo năng lực (hỗ trợ thực tập từ 3 - 6 triệu/tháng)

## 2. Mô tả công việc
* Tham gia phát triển hệ thống backend cho các dự án MiniApp, Web App sử dụng Java/Spring Boot.
* Thiết kế và tối ưu hóa cơ sở dữ liệu SQL Server, MySQL.
* Phối hợp với đội ngũ Frontend (Vue.js, React) để tích hợp APIs.
* Viết unit test để đảm bảo chất lượng code.

## 3. Yêu cầu công việc (Must-Haves)
* Có kiến thức cơ bản tốt về ngôn ngữ lập trình Java và phát triển ứng dụng Web.
* Hiểu biết về Framework Spring Boot (Spring MVC, Spring Data JPA, Spring Security).
* Biết sử dụng các công cụ quản lý mã nguồn: Git, Github.
* Tư duy logic tốt, chủ động học hỏi và có tinh thần trách nhiệm cao.

## 4. Điểm cộng (Nice-to-Haves)
* Sinh viên chuyên ngành CNTT hoặc các ngành liên quan từ các trường Đại học, Cao đẳng (FPT Polytechnic, Bách Khoa, v.v.).
* Có dự án cá nhân hoặc dự án học tập thực tế sử dụng Spring Boot.
* Biết cơ bản về Docker, VueJS hoặc Python là một lợi thế lớn.
