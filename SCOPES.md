# PrivOS permission contract

`privos-app.json` is the sole permission declaration. Every permission is Room-scoped. The source paths below inventory the current direct PrivOS calls and their HR consumers; the Task 8 repository path is identified explicitly where implementation is still pending. Missing optional grants must produce the stated degraded behavior rather than fabricated success.

| Scope | Requirement | Context | Execution identity | Existing HR source call sites | Behavior when missing |
|---|---|---|---|---|---|
